# 정수기 관리 안내

## 제품 개요

본 제품은 가정용 직수형 정수기로 별도의 저수조 없이 수돗물을 정수해 바로 공급한다. 정격 전압은
220볼트이며 소비 전력은 대기 상태에서 시간당 3와트다. 설치 장소는 직사광선을 피하고 벽면에서
10센티미터 이상 떨어뜨린다. 바닥이 고르지 않으면 진동과 소음이 생길 수 있으므로 수평을 맞춘 뒤
사용한다. 실내 온도가 영하로 떨어지는 곳에서는 내부 배관이 얼어 파손될 수 있다.

## 필터 교체 절차

[[gold:filter_steps]]필터를 교체할 때는 먼저 전원 코드를 뽑고 급수 밸브를 잠근다. 본체 앞면
커버를 아래로 당겨 분리하면 필터 세 개가 세로로 배열된 것이 보인다. 왼쪽부터 순서대로 세디먼트
필터, 카본 필터, 멤브레인 필터이며 교체 주기가 각각 다르다. 교체할 필터를 시계 반대 방향으로
90도 돌려 뽑고, 새 필터의 고무 패킹에 이물질이 없는지 확인한 뒤 같은 자리에 밀어 넣고 시계
방향으로 돌려 고정한다. 세 개를 한꺼번에 갈 때는 왼쪽부터 순서대로 진행해야 배관에 남은
물이 역류하지 않는다. 필터를 끼운 뒤에는 급수 밸브를 천천히 열어 누수가 없는지 1분간
확인한다. 이때 연결부에 물방울이 맺히면 패킹이 비뚤어진 것이므로 다시 분리해 끼운다.
마지막으로 커버를 닫고 전원을 연결한 다음, 정수 물을 2리터가량 흘려보내 초기 탄소 가루를
빼낸다. 흘려보낸 물은 마시지 말고 버리며, 물이 맑아질 때까지 반복한다. 교체 이력은 본체
측면 라벨에 날짜를 적어두면 다음 주기를 관리하기 쉽다. 작업 중 바닥에 물이 떨어질 수 있으므로
수건을 미리 깔아두고, 분리한 헌 필터는 물기를 뺀 뒤 비닐에 담아 일반 쓰레기로 배출한다.
교체를 마친 뒤에는 표시등 리셋 버튼을 3초간 눌러 주기 계산을 초기화해야 다음 알림이
정확하게 뜬다.[[/gold]] 이 과정을 생략하면 물에서 검은 입자가 나올 수 있다.

## 교체 주기

세디먼트 필터는 4개월, 카본 필터는 8개월, 멤브레인 필터는 24개월마다 교체한다. 사용량이 많거나
수질이 나쁜 지역은 주기를 앞당긴다. 본체 표시등이 주황색으로 바뀌면 교체 시기가 임박한 것이고
빨간색이면 즉시 교체해야 한다. 표시등은 교체 후 리셋 버튼을 3초간 눌러 초기화한다.

## 문제 해결

물이 나오지 않으면 급수 밸브가 열려 있는지, 정전은 아닌지 먼저 확인한다. 물맛이 이상하면 필터
수명이 다한 경우가 대부분이므로 교체 주기를 점검한다. 본체에서 물이 새면 즉시 전원을 끄고
급수를 차단한 뒤 서비스 센터에 연락한다. 소음이 커진 경우 수평이 틀어졌거나 배관에 공기가
들어간 것이니 수평을 다시 맞추고 물을 충분히 흘려보낸다.
